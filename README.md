# VRM-Companion

好きなVRMアバターと日本語で会話し、指定したフォルダの整理を任せられる、ローカル実行のデスクトップAIコンパニオン。

ユーザーが用意した任意のVRMアバターを使い、会話とPC作業の支援を行います。モデルの探索・選定・入手はユーザーに委ね、特定の外見やキャラクター設定を必須にしません。

## 現在の状態

対象PCは **Windows 11 Pro / RTX 5070 Laptop（VRAM 8GB）** です。初期版の提案構成は **Electron / TypeScript / Three.js + three-vrm / llama.cpp** とし、実機検証後に確定します。

MVPにはテキストチャットを含め、音声会話は含めません。

MVPのフォルダ整理は、指定フォルダ直下の通常ファイルを拡張子の固定ルールで分類する機能です。会話での依頼から整理案を作成し、一括承認後に移動します。実行記録と復元機能を備える設計です。
