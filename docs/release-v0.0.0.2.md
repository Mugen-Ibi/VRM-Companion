# VRM Companion v0.0.0.2 Beta

Windows x64向けのベータリリースです。公開バージョンは **0.0.0.2**、前回公開版はv0.0.1です。

## 主な変更

- **モーションを追加**：手振り・うなずき・おじぎ・伸び、視線・呼吸・自然なまばたき。「おだやか」「にぎやか」「オフ」を選べ、アバター画面や右クリックから手動再生できます。
- **ドラッグ中の表示を改善**：ドラッグ中のクリック透過切替を抑え、透明ウィンドウの再描画を要求。125% DPIで観測した移動時のウィンドウ寸法の増加を修正しました。
- **会話中にLLMを切替**：設定でGGUFフォルダーとllama-server.exeを指定し、会話上部の一覧からモデルを選択できます。前のモデルを停止してから次を読み込み、会話履歴を維持します。
- **リソース使用を抑制**：LLMの手動メモリ解放、未使用時の自動解放（既定5分）、次回送信時の再読込を追加。非表示アバターの描画とアニメーション予約を停止し、描画品質を選択できます。
- 起動済みの外部llama-serverへの接続も維持。外部プロセスは終了・再設定しません。
- llama.cppの共有環境・更新・起動・停止スクリプトを整理し、安定版と検証候補の管理を文書化しました。

## 起動と設定

1. `VRM-Companion-0.0.0.2-win32-x64.zip` を展開します。旧版を使用中の場合はトレイの「終了」で閉じます。
2. フォルダー内の `VRM-Companion.exe` を起動します。EXEだけを移動しないでください。
3. 「設定」で「フォルダーから選択」を選び、GGUFの配置フォルダーと展開済みllama.cppの `llama-server.exe` を指定して保存します。
4. 会話上部からモデルを選びます。既存サーバーを使う場合は「起動済みサーバーに接続」を選びます。
5. アバター画面から自分で用意したVRMをインポートします。未選択でもテキスト会話を利用できます。

VRM・GGUF・llama-serverは同梱しません。Node.jsとUnityは実行時に不要です。配布ZIPのSHA-256は添付の `SHA256SUMS.txt` で確認できます。

管理モードの既定はcontext 4096、並列1、batch 512 / ubatch 128、promptキャッシュRAM 0。GPU配置はllama.cppの自動調整を利用します。新しいllama.cppを使用してください（実機検証はb10964 / CUDA 13.3）。アプリ終了時はアプリが起動したLLMも終了します。

## 検証と既知の制限

- 型検査・書式検査成功。自動試験102件中101成功、既存の8.3短縮パス非対応環境によるスキップ1件。
- Windows 11 x64 / 8GB級NVIDIA GPUで、小型モデルと9B級モデルの選択・応答・切替・解放後の再読込・アプリ終了時の子プロセス停止を確認。
- 公式検証VRMで全4動作と、125% DPIで押下中のドラッグ表示・寸法維持を確認。非表示2.5秒間はアニメーション呼び出し0・WebGL描画0。
- 小さいモデルを選ぶことで必要メモリを抑えられますが、モデルの重みに必要なメモリは残ります。LLMを除く全プロセスメモリ1GBという仮目標は達成確認していません。
- 2時間連続表示試験はユーザー指定で後回しのままです。混在DPI・複数画面をまたぐドラッグ等は未確認です。
- 意図判定や会話品質は選択モデルに依存します。構造化出力や会話テンプレートが非対応のモデルは利用に失敗する場合があります。
- 整理はローカルNTFS・直下のみ。1計画200ファイル／2GiB、1ファイル512MiB。移動前の内容検証と承認が必要です。
- 音声会話、歩行・着座・外部モーションクリップ、コード署名、インストーラー、自動更新は含みません。

詳細は同梱の `docs/usage.md`、`docs/improvements.md`、`docs/verification.md` を参照してください。このベータ版は設計上のv0.1全受け入れ条件の完了を示すものではありません。
