# 2026-10-29 保守レビュー（ローカル準備）

この記録はLinux上のローカル検証です。過去のWindows実機測定とは区別します。新しいWindows配布物、GPU・実IME・NTFSでの合格、リモートCIやmainへの統合は宣言しません。署名必須の配布方針・保存形式・IPC API・外部llama-serverの取扱いは維持しています。

## 修正

- ローカルmanifestは署名ではないため、選択したllama-server.exeについて常にハッシュと実行権限を確認します。キャンセル、停止待ち中の中断、保存失敗で新しい実行権限を確定しません。GGUFフォルダー選択も停止・一覧取得後に中断を再確認します。
- GLBの先頭JSON・単一BIN、画像の整数参照・オフセット、正の有限整数の画像寸法を検証します。不正な入力が寸法検査や画像メモリ予算をすり抜けないようにします。同じメッシュを複数ノードで参照する場合も、各インスタンスを20万三角形の予算に含めます。これまで通過していた上限超過入力を拒否しますが、上限内の正常入力・保存形式は変更しません。
- Linux/WindowsのCIを追加。`npm run check` は型検査、書式、ビルド、テストを順に実施します。Windowsでは実NTFS補助EXEをビルドしてから試験し、他のOSでは24件のWindows専用試験を明示的にskipします。**Linux成功はWindows試験成功を意味しません。**
- 管理モデルの実機確認スクリプトはテスト用実行ファイルの同意を明示し、登録した実体パスを検査します。LLMベンチマークは、確認していない並行耐久試験やサーバー専有状態を測定条件として断定しません。
