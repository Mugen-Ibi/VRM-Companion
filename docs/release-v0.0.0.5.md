# VRM Companion v0.0.0.5 Beta

Windows x64向け。細粒度レビューで確認した、保存失敗・停止・モデル管理の不具合を修正しました。

- 受理前に送信が拒否されても下書きを保持。待機中の二重送信を防ぎ、新しく編集した下書きは消しません。
- 会話追加とタイトル変更は保存成功後に確定し、保存失敗でメモリとDBに異なる履歴が残ることを防ぎます。
- APIキー保存後にキー欄と削除チェックをリセット。削除後に新しいキーを登録できます。
- 停止・失敗した会話ターンをLLM文脈から除外し、userが連続することによるテンプレートエラーを防ぎます。画面の履歴は保持します。
- フォルダ登録にキャンセルを伝え、確定前に再確認。履歴削除もバックアップ処理後に停止を確認し、メインDBの削除を中断します。
- VRM登録の保存失敗時は未登録コピーを後処理。元のユーザー提供モデルには触れません。
- VRMメタデータの型、頂点数、accessor参照、描画形式を検査し、不正な負数で上限を相殺できないようにしました。
- 分割GGUFの2個目以降も再読み込み判定に含めます。

型検査・書式検査と、保存故障・キャンセル・分割モデル変更・不正VRMの回帰テストを実施。配布EXEで入力、APIキーの保存と再登録、会話・整理・復元、再起動、バックアップを検証しました。単体テストは124件中123成功・1スキップ。最終結果は [検証記録](verification.md) に記載します。

履歴削除の停止は、既にバックアップ内で削除済みの履歴を戻しません。VRMコピーをOS側の権限等で削除できない場合は通知し、手動確認が必要です。実Windows IME、透明ウィンドウの重なり、全モデルのテンプレート・実推論は検証範囲外です。

旧版をトレイの「終了」で閉じ、`VRM-Companion-0.0.0.5-win32-x64.zip`を新しいフォルダーに展開して起動してください。保存形式は変更していません。同じWindowsアカウントの通常起動では既存設定と履歴を引き継ぎます。添付の`SHA256SUMS.txt`でZIPを確認できます。
