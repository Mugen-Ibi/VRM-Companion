# VRM Companion v0.0.0.4 Beta

Windows x64向け。プロンプトと設定欄の入力操作を修正しました。

- 状態通知で画面全体を破棄する方式から、既存DOMを更新する方式へ変更。入力欄のフォーカス、選択範囲、Undo履歴を維持します。候補文の挿入や送信時のクリアは明示的に反映します。
- エラー通知を上部に配置し、高さを制限。長い通知が入力欄を覆い、クリックを遮る問題を修正しました。長文は通知内でスクロールできます。
- IME処理キー（229）、変換中のEnter、変換中の送信を保護しました。通常のEnter送信とShift+Enter改行は維持します。
- 再描画時のイベントハンドラー重複登録を防ぎ、入力の回帰検証スクリプトを追加しました。

型検査・書式検査、単体テスト、実Electronでの入力・Undo・IMEイベント・通知中の座標クリック、会話・整理・移動・復元・VRMインポートを検証しています。検証の証跡は [検証記録](verification.md) を参照してください。

Windowsの実キーボードによるIME操作、透明アバターと別ウィンドウの重なりに起因するフォーカス問題は、自動テストだけでは検証しきれていません。「通知のない起動直後からキャレットが出ない」という報告の原因確定・完全解消は宣言しません。

旧版をトレイの「終了」で閉じ、`VRM-Companion-0.0.0.4-win32-x64.zip`を新しいフォルダーに展開して起動してください。同じWindowsアカウントの通常起動では既存設定と履歴を引き継ぎます。保存形式は変更していません。EXE単体ではなく展開したフォルダー全体を保持してください。
