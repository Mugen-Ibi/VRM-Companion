# VRM Companion v0.0.1 Beta

Windows x64向けの初回ベータリリースです。

## 実装した機能

- ユーザー提供VRM 0.x / 1.0のインポート、透明表示、切替、移動、表示・非表示。
- ローカルllama.cppへの接続、日本語ストリーミングチャット、停止、人格設定、履歴管理。
- 明示選択したフォルダ直下の拡張子による整理案、内容検証、承認付き移動、復元。
- ファイル識別情報・SHA-256による検証、上書き防止、操作記録、障害後の照合。
- SQLiteバックアップ、破損時の復旧案内。

## 起動方法

1. `VRM-Companion-0.0.1-win32-x64.zip` を展開し、フォルダ内の `VRM-Companion.exe` を起動します。EXEだけを移動しないでください。
2. llama-serverを別途起動し、設定画面で接続を確認します。既定の接続先は `http://127.0.0.1:8080` です。
3. アバター画面から自分で用意したVRMをインポートします。未選択でもテキストチャットを利用できます。

VRM、GGUF、llama-serverは配布ZIPに含めません。Node.jsとUnityは実行時に不要です。`SHA256SUMS.txt` に配布ZIPのSHA-256を掲載します。

アバターはパネル右上または右クリックから隠せます。非表示状態は再起動後も維持します。パネルの×は非表示、アプリ終了はトレイの「終了」です。

## 検証と既知の制限

- 自動テスト95件成功、失敗0件、環境依存の8.3短縮パス試験1件をスキップ。
- Windows実機で配布EXEのチャット、停止、VRM切替、表示・非表示、再起動、バックアップを確認。
- 実NTFSのテスト用ファイルで承認付き整理と復元を確認。
- 2時間連続表示試験は利用者の指定により後回しとしており、完走は未確認です。
- アプリ全プロセスのメモリ合計1GBという仮目標は未達です。モデル切替試験で一時超過しています。
- 意図判定には誤分類が残ります。実行前に対象と整理案を確認してください。
- 整理はローカルNTFS・直下のみ。1計画200ファイル／2GiB、1ファイル512MiB。削除、上書き、再帰整理、任意コマンドは扱いません。
- 音声会話、コード署名、インストーラー、自動更新は含みません。DPI混在、モニター着脱、スリープ復帰などは未検証です。

この版はベータ版であり、設計上のv0.1完成条件をすべて満たした版ではありません。詳細は同梱の `docs/usage.md` と `docs/verification.md` を参照してください。
